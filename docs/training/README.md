# 培训路径

> 按身份选阅读路径。每份路径都是 **30-60 分钟读完 + 上手** 的最小集，不是穷举所有文档。
>
> 全部文档参考 [文档中心](../README.md)。

---

## 选我的路径

| 我是… | 我要做的事 | 入口 |
|-------|----------|------|
| **开发 / 工程师** | 接手代码、做需求、修 bug、加新能力 | [→ developer.md](./developer.md) |
| **使用者 / 作家 / 创作** | 用 CLI / Workbench / Writer Studio 做拆书、问答、仿写 | [→ user.md](./user.md) |
| **运维 / 实施** | 部署、自检、排障、生产长跑监控 | [→ operator.md](./operator.md) |
| **业务 / 产品 / 销售** | 给客户讲能力、谈商业化、做 Demo | [→ business.md](./business.md) |

---

## 通用前置（任何角色都建议先读）

1. [文档中心](../README.md)（5 分钟） — 知道有什么、去哪找
2. [OVERVIEW.md](../OVERVIEW.md)（5 分钟） — 一页读懂系统
3. [GLOSSARY.md](../GLOSSARY.md)（按需查阅） — 遇到陌生词来这里
4. [ROADMAP.md](../ROADMAP.md)（5 分钟） — 知道当前做到哪、下一步去哪
