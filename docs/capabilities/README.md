## 设计原则

每份 capability landing 都遵循统一结构：

1. **一句话定位** — 这条线干什么
2. **能解决什么问题** — 用户视角
3. **当前能做到什么** — 实证 + 边界
4. **怎么用** — CLI / API / UI 任选一条
5. **架构概览** — 不是细节，只是知道有哪些组件
6. **路线图** — 当前进度 + 下一步
7. **深入文档索引** — 按需深入
