# 范例：教育贷/阶层焦虑 → 修仙映射（《没钱修什么仙？》分析）

> 项目：源材料分析（非生成）
> 痛点：教育贷 / 阶层固化 / 寒门难出贵子

---

## Step 1：痛点解构

痛点: 教育贷/阶层焦虑

核心矛盾:
1. **个体努力 vs 系统壁垒** — 再努力也跨不过阶层鸿沟
2. **教育承诺 vs 现实回报** — 读书改变命运是谎言还是真理
3. **借贷自由 vs 债务陷阱** — 看似给你机会，实则套牢你
4. **天赋 vs 资源** — 没有灵根也能修仙，但代价是终身负债
5. **家庭牺牲 vs 个人追求** — 母亲卖掉一切供你修仙
6. **短期快感 vs 长期代价** — 药物/借贷让你暂时跟上，但越陷越深

---

## Step 2：修仙概念映射

| 修仙概念 | 现实映射 | 讽刺锚点 |
|----------|---------|---------|
| 灵气/法力 | 金钱/教育资源 | 没钱 = 没灵气 = 修不了仙 |
| 灵根 | 先天条件（家境/户口/学区） | 没灵根也能修，但要花 10 倍钱 |
| 宗门 | 重点学校/补习机构 | 学费极贵，但不上就没出路 |
| 丹药 | 神经兴奋填充剂/补课 | 让你暂时跟上，但有副作用 |
| 天灵根 | 顶级教育资源（可租借） | 租一小时就要几千块 |
| 借贷 | 教育贷/消费贷 | 利滚利，永远还不完 |
| 修仙 | 上大学/阶层跃迁 | 所有人都说这是唯一出路 |
| 凡人 | 没有修仙资格的底层 | 连尝试的机会都没有 |
| 飞升 | 考上顶尖大学/加入大宗门 | 传说中的成功，极少数人达到 |

## Step 3：世界结构

### 经济系统
- 仙道技术垄断一切（粮食/能源/教育/医疗/金融）
- 普通人必须通过「修仙」才能获得基本福利
- 修仙需要持续投入金钱（药物/设备/学费）
- 借贷平台无处不在，利率极高

### 权力结构
- 大宗门 = 垄断集团，控制一切
- 政府/军队 = 宗门的保安
- 学校 = 宗门的筛选机器
- 底层 = 永远在还债的打工人

### 修炼机制
- 没有灵根也能修仙（仙道技术突破）
- 但需要持续购买药物/设备维持
- 停止投入 = 修为倒退
- 本质：把修仙变成了终身消费

### 社会分层
- 昆墟 36 层 + 地下 18 层
- 越往上越好，底层是贫民窟
- 阶层标志：住在哪一层
- 流动性：理论上可以往上爬，实际上极难

## Step 4：主角原型

```
原型: 底层逆袭（穿越）
名字: 张羽
前世: 现代人，穿越到修仙世界的底层高中生身上
起点: 欠债 70 万，零资源，但有现代人的认知优势
核心矛盾: 想修仙但没钱 / 不想借贷但不借就修不了
金手指: 羽书（属性面板 + 技能升级系统，但需要大量重复练习）
限制: 金手指不给钱，只给方向；仍然需要在经济系统内生存
```

## Step 5：讽刺锚点（节选）

```
锚点 #1 (第 1 章):
  现实原型: 毕业面试被各种门槛拒绝
  修仙化表现: 面试修仙岗位，要么门槛高不可攀，要么合同是陷阱
  讽刺层次: 细想心酸（努力学习多年，发现和不学的人没区别）
  角色反应: 张羽呆坐，母亲发来「不论绝育还是变性手术钱妈妈帮你凑」

锚点 #2 (第 1 章):
  现实原型: 教育贷/消费贷的诱惑
  修仙化表现: 补习班免学费但暗藏借贷，母亲以为是好事
  讽刺层次: 再想愤怒（系统设计让你不知不觉陷入债务）
  角色反应: 母亲为儿子「受赏识」而高兴，不知道一切都是贷款

锚点 #3 (第 8 章):
  现实原型: 班主任/学校诱导学生签不平等合同
  修仙化表现: 班主任以「关心」名义诱导签债务重组合同
  讽刺层次: 表面好笑（修仙界也有 PUA），细想心酸（信任被利用）
  角色反应: 张羽识破拒绝，但大部分同学签了
```

## Step 6：差异化参考

本范例作为「经济焦虑」类讽刺修仙的标杆，后续新项目需要与之差异化的维度：
- 痛点内核不能是「没钱」
- 世界结构不能是「宗门垄断 + 借贷」
- 主角不能是「穿越底层从零开始」
- 讽刺手法可以复用「荒诞放大」，但锚点场景必须不同
