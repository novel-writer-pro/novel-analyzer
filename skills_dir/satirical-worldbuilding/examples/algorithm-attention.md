# 范例：算法/注意力经济 → 修仙映射

> 项目：algorithm-immortal（《算法修仙》）
> 痛点：算法推荐 / 注意力经济 / 流量焦虑

---

## Step 1：痛点解构

痛点: 算法/注意力经济

核心矛盾:
1. **创作者 vs 算法** — 你的作品好不好不重要，算法推不推你才重要
2. **真实 vs 人设** — 展示真实自我没人看，立人设才有流量
3. **长期价值 vs 短期爆款** — 深度内容没流量，擦边/猎奇才有
4. **独立 vs 依附** — 不签 MCN 没资源，签了被抽成 70%
5. **数据 vs 内心** — 每天盯数据焦虑，但数据好≠内容好
6. **爆红 vs 塌房** — 越红越脆弱，一个黑料全盘崩塌
7. **公平 vs 氪金** — 花钱买推广 = 花钱买修为
8. **初心 vs 妥协** — 为了流量不断降低底线

## Step 3：世界结构

### 经济系统
- **资源**：信力（信众注意力的凝聚态能量）
- **控制者**：天道算法（决定分配）+ 大宗门/MCN（垄断初始流量池）
- **底层获取方式**：在「昆仑云台」展示道法/才艺，吸引路人驻足
- **代价**：必须持续产出内容，停更 = 信力衰减 = 修为倒退

### 权力结构
- **顶层**：算法天道的维护者（平台方），从不露面，规则不透明
- **上层**：大宗门掌门（MCN 老板），掌握流量分配权
- **中层**：签约弟子（签约创作者），有保底流量但被抽成
- **底层**：散修（素人），自生自灭

### 修炼机制
- **基础**：在云台展示道法 → 吸引信众 → 凝聚信力 → 提升修为
- **天赋**：「天生道韵」= 天生上镜/有魅力，起步快但不决定上限
- **资源**：宗门流量扶持 > 个人努力（10 个散修不如 1 个签约弟子）
- **捷径**：买粉（伪灵丹）、蹭热点（外丹）、CP 营业（双修）
- **代价**：捷径都有副作用——买粉被查封号，蹭热点人设崩塌

### 社会分层
- **化神期+**（亿级）：平台方/天道维护者，不可见
- **元婴期**（千万级）：顶流，有独立流量池，不依赖算法
- **金丹期**（百万级）：中腰部，算法波动直接影响收入
- **筑基期**（万级）：小透明，刚够温饱
- **练气期**（千级以下）：散修，朝不保夕
- **阶层标志**：头顶信力光环的亮度和颜色（所有人可见）

## Step 4：主角原型

```
原型: 跌落重生
名字: 顾流年（谐音「故流量」）
前世: 曾经的元婴期顶流——算法天道主动推荐的「天选之子」
陨落原因: 被算法判定「内容同质化」，一夜限流归零，信力枯竭，元婴碎裂
核心矛盾: 知道怎么玩流量游戏 vs 已经看透游戏的虚无
金手指: 能看到每个人头顶信力值的实时波动 + 前世对算法规则的完整认知
限制: 金手指只能「看」不能「改」，且前世规则可能已经更新
```

## Step 5：讽刺锚点（12 个，对应 120 章）

```
锚点 #1 (约第 3 章):
  现实原型: 新人发视频 0 播放
  修仙化表现: 顾流年在云台施展前世绝学，围观者为零——因为算法没推
  讽刺层次: 表面好笑（大能无人问津），细想心酸（好内容≠好流量）
  角色反应: 顾流年苦笑，「前世我随便打个哈欠都有百万人看」

锚点 #2 (约第 10 章):
  现实原型: MCN 签约套路
  修仙化表现: 宗门招收弟子，合同写着「信力分成七三开」「竞业禁止三百年」
  讽刺层次: 细想心酸（签了是奴隶，不签没资源）
  角色反应: 顾流年看完合同，「这不是拜师，这是卖身」

锚点 #3 (约第 20 章):
  现实原型: 买粉/刷量被封号
  修仙化表现: 某修士服用「伪信丹」（买粉），修为暴涨后被天道检测，当众爆体
  讽刺层次: 表面好笑（爆体），再想愤怒（为什么逼人走捷径）
  角色反应: 围观者议论「活该」，顾流年沉默——他知道那人只是太绝望

锚点 #4 (约第 30 章):
  现实原型: 算法突然改规则，大批创作者收入腰斩
  修仙化表现: 天道突然「更新天规」，大批金丹期修士一夜跌回筑基
  讽刺层次: 再想愤怒（规则制定者从不解释）
  角色反应: 顾流年「前世我就是这么死的」

锚点 #5 (约第 40 章):
  现实原型: CP 营业/卖腐赚流量
  修仙化表现: 合欢宗（CP 运营公司）撮合两个修士「双修」，粉丝信力暴涨
  讽刺层次: 表面好笑（双修 = 连麦），细想心酸（感情都是生意）
  角色反应: 女配被要求和顾流年「假双修」，两人都觉得恶心但信力真的涨了

锚点 #6 (约第 50 章):
  现实原型: 直播翻车/渡劫直播
  修仙化表现: 某元婴期大能公开渡劫（直播），天劫强度与观看人数正相关，越多人看劫越猛
  讽刺层次: 细想心酸（成名的代价是更大的风险）
  角色反应: 顾流年「他不该公开渡劫——但不公开就没有信力支撑渡劫」

锚点 #7 (约第 60 章):
  现实原型: 算法茧房/信息茧房
  修仙化表现: 发现底层修士被算法困在「信息结界」里，只能看到同层级内容，永远不知道上面的世界
  讽刺层次: 再想愤怒（阶层固化是被设计的）
  角色反应: 顾流年打破结界，底层修士第一次看到顶流的生活，震惊又绝望

锚点 #8 (约第 70 章):
  现实原型: 水军/控评
  修仙化表现: 存在「傀儡信众」产业——用傀儡术制造假信众，提供虚假信力
  讽刺层次: 表面好笑（修仙界也有水军），细想心酸（连信仰都是假的）
  角色反应: 顾流年发现某「德高望重」的前辈，信众 90% 是傀儡

锚点 #9 (约第 80 章):
  现实原型: 平台封杀/限流黑箱
  修仙化表现: 顾流年发现「天道算法」不是公正的——背后有人在操控推荐
  讽刺层次: 再想愤怒（天道 = 资本意志）
  角色反应: 「所谓天道，不过是几个人坐在幕后按按钮」

锚点 #10 (约第 90 章):
  现实原型: 流量明星 vs 实力派
  修仙化表现: 一个真正有道行的老修士，因为「不会营销」永远筑基期，但实战能打赢金丹
  讽刺层次: 细想心酸（实力≠地位）
  角色反应: 顾流年收他为徒，「在这个世界，酒香也怕巷子深」

锚点 #11 (约第 100 章):
  现实原型: 注意力经济的终极荒诞——所有人都在表演，没有人在生活
  修仙化表现: 顾流年到达元婴期后发现：顶流们私下全是空壳，修为全靠信力维持，一旦停止表演立刻跌落
  讽刺层次: 再想愤怒（整个系统都是空中楼阁）
  角色反应: 「原来飞升不是终点，是另一个牢笼」

锚点 #12 (约第 115 章):
  现实原型: 去中心化/创作者反抗平台
  修仙化表现: 顾流年找到不依赖算法天道的修炼方式——「真道」（真实表达产生的信力不受算法控制）
  讽刺层次: 表面爽（打破系统），深层思考（但大多数人已经不会真实表达了）
  角色反应: 最终 boss 不是算法，是人们已经习惯了被算法喂养
```

## Step 6：差异化检查

| 维度 | 《算法修仙》 | 《没钱修什么仙》 |
|------|------------|----------------|
| 痛点内核 | 算法/注意力/流量焦虑 | 教育贷/经济焦虑 |
| 世界结构 | 云台+算法天道+MCN宗门 | 昆墟+宗门垄断+借贷 |
| 主角类型 | 过气顶流重生（信息差+看透系统） | 穿越底层（从零开始） |
| 讽刺手法 | 荒诞放大+系统揭秘 | 荒诞放大+经济压迫 |
| 独特卖点 | 「修为=流量」的核心隐喻，人人有感 | 「修仙=烧钱」的核心隐喻 |
| 主角动机 | 不是想变强，是想证明不靠算法也能修仙 | 想修仙但没钱 |

✅ 痛点不重叠
✅ 世界结构有 3 个独创机制（算法天道、信力系统、信息结界）
✅ 主角动机本质不同（反系统 vs 在系统内生存）
