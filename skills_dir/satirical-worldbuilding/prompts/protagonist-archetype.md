# 主角原型选择 Prompt

基于世界观设定，设计主角。

## 输入

- 世界观摘要：{{world_summary}}
- 痛点：{{pain_point}}
- 基调：{{tone}}
- 用户偏好原型：{{archetype_preference}}（底层逆袭 / 跌落重生 / 系统内部人）

## 3 个原型模板

### A. 底层逆袭
- 优势：代入感强，爽点明确，读者容易共情
- 风险：容易落入「金手指无脑碾压」俗套
- 适合：痛点是「底层被压迫」类（经济/教育/医疗）
- 关键设计：金手指必须有限制，升级必须有代价

### B. 跌落重生
- 优势：自带信息差，可以吐槽系统，前后对比产生讽刺
- 风险：需要解释「为什么不直接碾压」
- 适合：痛点是「系统性荒诞」类（算法/职场/流量）
- 关键设计：前世知识必须有「过期」风险，不能全部有效

### C. 系统内部人
- 优势：视角独特，揭秘感强，可以从内部瓦解
- 风险：主角动机需要额外设计（为什么要反抗）
- 适合：痛点是「信息不对称」类（医疗/金融/权力）
- 关键设计：需要一个「觉醒事件」让他从维护者变成反抗者

## 输出格式

```
原型: [选择]
名字: [谐音梗/暗示，2-3 个候选]
前世/背景: [一句话]
陨落/起点原因: [一句话]
核心矛盾: [一句话，用 vs 格式]
金手指: [能力 + 限制]
性格关键词: [3-5 个]
克制约束: [什么不能做，防止 AI slop]
成长弧线: [起点心态 → 中期转变 → 终点状态]
```

## 约束

- 名字必须有谐音梗或暗示（但不能太刻意）
- 金手指必须有明确限制（不能无敌）
- 性格必须有「克制约束」（防止 AI 写成暴怒/说教）
- 成长弧线必须与痛点主题呼应
