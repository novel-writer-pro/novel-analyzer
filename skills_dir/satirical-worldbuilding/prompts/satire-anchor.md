# 讽刺锚点设计 Prompt

基于世界观和角色设定，设计贯穿全书的讽刺锚点。

## 输入

- 世界观：{{world_summary}}
- 角色：{{characters}}
- 章节规模：{{total_chapters}}
- 痛点：{{pain_point}}

## 输出要求

每 10 章至少 1 个锚点，总计至少 12 个。

### 锚点格式

```
锚点 #N (约第 X 章):
  现实原型: [什么现实场景/现象]
  修仙化表现: [在小说里怎么呈现]
  讽刺层次: [表面好笑 / 细想心酸 / 再想愤怒 / 引发思考]
  涉及角色: [谁参与]
  角色反应: [主角/配角怎么反应，体现什么]
  与主线关系: [推动剧情 / 揭示世界观 / 角色成长]
```

### 讽刺层次分布建议

- 第一卷（1-30）：以「表面好笑」和「细想心酸」为主，建立基调
- 第二卷（31-60）：加入「再想愤怒」，升级讽刺深度
- 第三卷（61-90）：以「再想愤怒」为主，揭露系统本质
- 第四卷（91-120）：加入「引发思考」，不给简单答案

### 质量标准

- [ ] 不能是「作者跳出来解释讽刺」（meta_commentary = blocker）
- [ ] 必须通过情节/对话/细节自然呈现
- [ ] 读者即使不 get 讽刺，也能当正常剧情看（双层阅读）
- [ ] 每个锚点都与主线有关联（不是独立小品）
- [ ] 锚点之间有递进关系（不是平行罗列）

## 约束

- 讽刺通过「展示」而非「告诉」
- 主角的吐槽用内心独白，不用对白说教
- 配角的荒诞行为要有内在逻辑（他们不觉得自己荒诞）
- 避免「全员恶人」——系统的问题 > 个人的恶意
