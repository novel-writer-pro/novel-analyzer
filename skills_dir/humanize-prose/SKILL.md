# humanize-prose

## 定位

生成后的「治疗」层。当 `ai-detection-validator` 检测到问题段落后，本 skill 对这些段落做精准重写，保留语义但改变表达方式。

**核心原则：不改内容，只改表达。读者读到的信息完全相同，但文字的「手感」从 AI 变成人。**

---

## 6 种人味化手段

### 手段 1：句式打散 (Sentence Breaking)

把均匀的句子改成长短交替。

```
AI 原文：
  顾流年站在窗边看着外面的街道。街道上行人来来往往。每个人头顶都有数字。数字大小不一。

人味化后：
  窗外。
  街道挤满了人，脚步声混着叫卖声灌进来，每个脑袋上面都顶着数字——大的小的，跳的不跳的，像一片会动的菜市场价签。
```

**规则**：
- 找到连续 3+ 句句长相近的段落
- 合并短句为长句，或拆分长句为碎片
- 插入 1-3 字的爆发句

### 手段 2：词汇替换 (Vocabulary Swap)

把高频 AI 词替换为低频同义词或口语化表达。

```
替换表（部分）：
  看到 → 瞅见/瞟到/扫了一眼
  走过 → 蹭过去/溜过/挪过
  说道 → 嘟囔/嗤了一声/冒出一句
  感觉 → 总觉着/心里头
  突然 → 冷不丁/一下子
  非常 → 贼/忒/要命地
  开始 → 动手/着手 → 直接删掉（「他开始跑」→「他跑了」）
```

**规则**：
- 每 500 字至少 3 处替换
- 替换后必须符合角色语域（顾流年用冷幽默，林七七用天真口吻）
- 不能为了替换而生硬

### 手段 3：节奏注入 (Rhythm Injection)

在关键位置插入极短句制造突发性。

```
AI 原文：
  他看着那个数字从三千六百万一路下降到零，心中充满了绝望和不甘。

人味化后：
  三千六百万。两千万。九百万。一百万。
  零。
  完了。
```

**规则**：
- 情绪高点用极短句（1-4 字）
- 信息密集处用长句
- 过渡处用中等句
- 制造「呼吸感」——读者读到短句时会不自觉加快

### 手段 4：口语化 (Colloquialization)

对话和内心独白加入口语标记。

```
AI 原文：
  "你为什么不签约呢？"钱多多问道，"不签约的话你永远都是练气期。"

人味化后：
  "你咋不签呢？"钱多多嘴里还嚼着东西，含含糊糊的，"不签……你就一辈子练气，懂不？"
```

**规则**：
- 对话中加入：省略（「那个……」）、语气词（「嘛」「呗」「啊」）、断句、重复
- 内心独白加入：自问自答、不完整念头、吐槽
- 叙述中偶尔混入口语化表达（「这玩意儿」「得了」）
- 注意角色区分：不同角色的口语化程度不同

### 手段 5：不完美注入 (Imperfection Injection)

故意加入一些「不规范」但有味道的表达。

```
手段：
- 偶尔用错标点（破折号代替逗号）
- 偶尔用不完整句（「要是……算了。」）
- 偶尔重复词（「远，很远。」）
- 偶尔用非标准比喻（「像被人往脑子里塞了一团湿棉花」）
- 偶尔打破叙事视角（突然插入一句旁白式吐槽）
```

**规则**：
- 每章 3-5 处，不能太多（太多就是另一种 AI 味）
- 必须自然，不能刻意
- 不完美 ≠ 错误（语法错误不是人味，是 bug）

### 手段 6：风格标记注入 (Voice Marker Injection)

从源小说提取作者特有的表达习惯，注入生成文本。

```
从《没钱修什么仙？》提取的风格标记：
- 章末常用「……」省略号留白
- 内心独白用引号括起来（不用斜体）
- 场景切换用「……」单独一行
- 数字喜欢用阿拉伯数字而非汉字
- 对话后的动作描写紧跟，不另起段
- 喜欢用「便」代替「就」
- 转折喜欢用短句直接切，不用连接词
```

**规则**：
- 从源小说分析中提取 10-15 个风格标记
- 每章注入 5-8 个（不是全部，避免过度模仿）
- 风格标记必须自然融入，不能生硬

## 重写流程

```
输入: 原文 + ai-detection-validator 的问题报告

Step 1: 按问题类型分类
  - 句长均匀 → 手段 1 (句式打散) + 手段 3 (节奏注入)
  - 禁用词 → 手段 2 (词汇替换)
  - 句式重复 → 手段 1 (句式打散) + 手段 5 (不完美注入)
  - 连接词过多 → 手段 2 (词汇替换，直接删除连接词)
  - 情感直述 → 手段 4 (口语化) + 展示性重写

Step 2: 段落级重写（只改问题段落，不动通过的段落）

Step 3: 注入风格标记（全文级别，3-5 处）

Step 4: 验证
  - 语义保持：重写前后的关键信息点必须一致
  - AI 检测分下降
  - 风格一致性：与前后章节的 style_drift 在阈值内
```

## Prompt 模板（喂给 LLM 做重写）

```
你是一个中文网文润色师。你的任务是对以下段落做「人味化」重写。

【规则】
1. 保留所有剧情信息和角色行为，只改表达方式
2. 句长必须有大波动（最短≤5字，最长≥35字）
3. 删除所有禁用词：渐渐/缓缓/微微/淡淡/似乎/仿佛/宛如
4. 把「他感到X」改为身体反应或行为描写
5. 对话加入口语标记（省略/语气词/断句）
6. 在情绪高点插入极短句（1-4字）
7. 用低频词替代高频词（至少2处）

【问题诊断】
{{problem_description}}

【原文】
{{original_paragraph}}

【角色语域参考】
{{character_voice_reference}}

【输出】
直接输出重写后的段落，不要解释。
```

## 与其他组件的关系

| 组件 | 阶段 | 作用 |
|------|------|------|
| `anti-ai-generation-constraints` | 生成前 | 预防（prompt 约束） |
| `satire-anti-slop-guard` | 生成后 | 检测讽刺文 slop |
| `ai-detection-validator` | 生成后 | 检测 AI 味 |
| **`humanize-prose`（本 skill）** | **检测后** | **治疗（段落重写）** |
| `style_calibration_service` | 重写后 | 验证风格一致性 |
| `reader_panel_service` | 最终 | 验证可读性未下降 |

## 成本估算

| 场景 | 额外 LLM 调用 | 额外时间 |
|------|-------------|---------|
| 全章通过（无问题段落） | 0 | 0 |
| 3-5 个问题段落 | 1 次（批量重写） | ~30s |
| 全章问题严重 | 2-3 次（分批重写+验证） | ~90s |

平均每章额外成本：~1 次 LLM 调用，~30s。相比生成的 175s，增加 17%。
