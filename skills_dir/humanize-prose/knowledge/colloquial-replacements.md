# 口语化替换词表

> 用于 humanize-prose 的词汇替换环节。左边是 AI 高频词，右边是人味替换。
> 按角色语域分级：通用 / 顾流年专用 / 钱多多专用 / 白鹿专用

## 通用替换（所有角色可用）

| AI 高频词 | 人味替换（随机选一个） |
|-----------|---------------------|
| 显然 | 明摆着、一看就知道、谁都看得出 |
| 因此 | 所以呗、得了、那就 |
| 然而 | 可偏偏、结果呢、谁知道 |
| 但是 | 可、就是吧、话说回来 |
| 首先/其次/最后 | 删掉，用时间顺序或动作承接 |
| 综上所述 | 删掉，直接说结论 |
| 不得不说 | 删掉 |
| 值得注意的是 | 删掉 |
| 事实上 | 说白了、其实吧 |
| 毫无疑问 | 删掉，或改为「这还用说？」 |
| 与此同时 | 删掉，用段落切换表示同时 |
| 突然 | 冷不丁、一下子、猛地 |
| 非常/十分/极其 | 贼、忒、要命地、删掉（直接用强动词） |
| 开始 | 删掉（「他开始跑」→「他跑了」） |
| 看到 | 瞅见、瞟到、扫了一眼、入眼的是 |
| 走过来 | 蹭过来、凑过来、晃过来 |
| 说道 | 嘟囔、嗤了一声、冒出一句、开口 |
| 感觉 | 总觉着、心里头、隐约 |
| 似乎/仿佛 | 像是、八成是、大概 |
| 渐渐 | 一点一点、慢慢地（限用）、或直接删掉 |

## 顾流年专用（懒散毒舌冷幽默）

| 场景 | 专属表达 |
|------|---------|
| 吐槽系统 | 「挺好，天道起名这块一直稳定发挥，缺德得很有辨识度。」 |
| 评价他人 | 「命挺硬，就是剧本太寒酸。」 |
| 自嘲 | 「故流量，名副其实。」 |
| 看透但无奈 | 「知道又怎样，知道了也得吃饭。」 |
| 形容穷 | 「不是不想动，是身体太穷。」 |
| 形容荒诞 | 「连拒绝都要收费，商业化修仙已经走到了相当成熟的阶段。」 |
| 内心独白标记 | 短句 + 句号。不用感叹号。冷的。 |

## 钱多多专用（精明市侩但不坏）

| 场景 | 专属表达 |
|------|---------|
| 劝人 | 「兄弟，道心值几个钱？」 |
| 算账 | 「一天被动收入三千灵石，你那道心能换三千灵石吗？」 |
| 自我安慰 | 「信众觉得真实就是真实。」 |
| 口头禅 | 「懂不？」「你算算。」「这笔账怎么算都不亏。」 |

## 白鹿专用（倔强真诚）

| 场景 | 专属表达 |
|------|---------|
| 坚持 | 「我的道法就是我想表达的东西。看不看是他们的事。」 |
| 质疑 | 「你说你看透了？看透了还在玩，那叫什么看透？」 |
| 拒绝 | 不解释，直接「不。」或沉默 |
| 口头禅 | 很少用语气词，句子干净利落 |

## 林七七专用（天真热血）

| 场景 | 专属表达 |
|------|---------|
| 提问 | 「顾前辈，为什么……是我不够努力吗？」 |
| 困惑 | 「可是……如果好的道法没人看，那修炼它还有什么意义？」 |
| 口头禅 | 「真的吗？」「那怎么办？」 |
| 特征 | 喜欢用问句，句尾常带「吗」「呢」 |

## 场景转换替换

| AI 写法 | 人味写法 |
|---------|---------|
| 「与此同时，在另一边……」 | 直接切场景，用「——」或空行 |
| 「时间来到了第二天」 | 「天亮了。」或直接写第二天的动作 |
| 「就在这时」 | 删掉，直接写发生的事 |
| 「不知过了多久」 | 「等他回过神」或具体时间标记 |
| 「画面一转」 | 不写，用段落分隔 |

## 情绪展示替换

| AI 直述 | 人味展示 |
|---------|---------|
| 他感到愤怒 | 他的拳头攥紧了 / 指甲掐进肉里 |
| 她很开心 | 她嘴角往上翘，怎么压都压不住 |
| 他很紧张 | 手心全是汗 / 咽了口唾沫 |
| 她感到悲伤 | 鼻子一酸 / 眼眶热了 / 喉咙像堵了什么 |
| 他很震惊 | 脚步顿住 / 瞳孔一缩 / 脑子嗡了一下 |
| 她感到害怕 | 后背发凉 / 汗毛竖起来 / 腿软了 |
| 他很失望 | 笑了一下，没说话 / 转身走了 |
| 她很无奈 | 叹了口气 / 「行吧。」 |
