# elastic-plot-expansion

## 定位

长篇网文的弹性扩展系统。核心主线不变，通过「弹性插槽」机制在任意位置插入新的世界层、势力、角色弧线，实现从 200 章到 300/500 章的平滑扩展。

**核心原则：扩写 ≠ 注水。每一章新增内容必须满足「三有」标准：**
1. **有生命**：推动至少一个角色的内在成长
2. **有价值**：揭示世界观的新维度或深化已有维度
3. **有表现力**：给读者带来新的认知或情感体验

---

## 适用场景

- 已有完整主线骨架，需要扩展总章数
- 根据市场/读者反馈，在特定位置加入新元素
- 角色弧线需要更多空间展开
- 世界观需要更多层次揭示

---

## 核心概念

### 弹性插槽 (Elastic Slot)

在主线核心节点之间预留的可扩展位置。每个插槽定义：

```yaml
slot:
  id: "slot-暗网世界层"
  position: "ch41-50之间"
  min_chapters: 5        # 最少展开章数
  max_chapters: 15       # 最多展开章数
  default_chapters: 10   # 默认展开章数
  prerequisites:         # 前置条件
    - "ch40 卷末事件已发生"
    - "暗网概念已在 ch37 引入"
  content_type: "world_layer"  # world_layer | character_arc | faction | mystery
  expansion_seed:        # 扩展种子（核心冲突/问题）
    - "暗网云台的规则是什么？"
    - "谁在暗网中掌权？"
    - "主角如何在暗网中生存？"
  character_growth:      # 必须推动的角色成长
    - "顾流年: 认识到算法之外还有另一套规则"
    - "白鹿: 发现暗网中有真正坚持真实的人"
  exit_condition:        # 退出条件（何时回到主线）
    - "获得暗网中真道修士的线索"
    - "建立暗网中的盟友关系"
```

### 核心节点 (Core Node)

不可删减的主线关键事件。核心节点之间的距离决定了可插入的弹性空间。

### 扩展种子 (Expansion Seed)

每个弹性插槽的「问题集」——回答这些问题就是扩展的内容。问题越多，可展开的章数越多。

## 扩展流程（6 步）

### Step 1：确定扩展目标

```
当前章数: N
目标章数: M
需要新增: M - N 章
```

### Step 2：评估现有插槽容量

```
现有插槽总容量 = Σ(每个插槽的 max_chapters - 当前 chapters)
如果容量 ≥ 需要新增 → 扩展现有插槽
如果容量 < 需要新增 → 需要创建新插槽
```

### Step 3：创建新插槽（如需要）

新插槽必须满足：
1. 不打断核心节点的因果链
2. 引入至少 1 个新元素（世界层/势力/角色/谜题）
3. 与主线冲突有关联（不是独立小品）
4. 有明确的进入条件和退出条件

**新插槽类型模板：**

| 类型 | 适合位置 | 典型章数 | 示例 |
|------|---------|---------|------|
| world_layer | 卷与卷之间 | 10-20 | 新的世界层/平台/空间 |
| character_arc | 卷中段 | 5-15 | 配角独立弧线/新角色引入 |
| faction | 任意位置 | 5-10 | 新势力/组织出现 |
| mystery | 高潮前 | 5-10 | 新谜题/真相的新层次 |
| challenge | 升级前 | 5-10 | 新的考验/试炼 |
| aftermath | 高潮后 | 3-8 | 事件余波/角色消化 |

### Step 4：设计插槽内容

每个插槽展开时，必须回答：

```
1. 这段内容揭示了什么新东西？（世界观/角色/主题）
2. 哪个角色在这段内容中成长了？怎么成长的？
3. 读者读完这段会获得什么？（情感/认知/爽感）
4. 这段内容如何连接回主线？（不能是死胡同）
5. 删掉这段内容，主线是否仍然成立？（必须是 Yes，否则应该是核心节点）
```

### Step 5：验证扩展质量

**三有检查（每章必须通过）：**

- [ ] 有生命：本章推动了 ≥1 个角色的内在变化
- [ ] 有价值：本章揭示了 ≥1 个新信息/新维度
- [ ] 有表现力：本章有 ≥1 个让读者产生情感反应的场景

**节奏检查：**

- [ ] 扩展后每 30 章仍有 1 个高潮节点
- [ ] 没有连续 5 章以上的「平淡期」
- [ ] 张力曲线仍然整体上升

**连续性检查：**

- [ ] 新内容与前后章节无矛盾
- [ ] 角色行为与已建立的性格一致
- [ ] 世界观设定无冲突
- [ ] 信力/境界数值连续

### Step 6：更新主线文档

扩展完成后，更新 `plot/arcs.md`：
- 新增的插槽写入弹性插槽表
- 核心节点的章号可能需要后移
- 角色成长弧线需要更新
- 张力曲线需要重绘

## 扩展原则（不可违反）

### 人物原则

1. **角色不是工具**：新章节中的角色必须有自己的动机和情感，不是为了推动剧情而存在
2. **成长不可回退**：除非有明确的创伤事件，角色的认知/能力不能倒退
3. **新角色有生命**：即使是临时角色，也必须有一个「让读者记住的特征」
4. **关系有层次**：角色之间的关系不能只有「盟友/敌人」，要有灰色地带

### 世界观原则

1. **新层次不矛盾**：新揭示的世界观信息不能与已有设定冲突
2. **逐步揭秘**：不要一次性倾倒所有信息，每次只揭示一层
3. **有内在逻辑**：新的世界层/势力必须有存在的理由
4. **与主题相关**：新元素必须与核心主题（自由 vs 系统）有关联

### 节奏原则

1. **30 章一高潮**：无论怎么扩展，每 30 章必须有一个情绪高点
2. **不连续平淡**：不能有连续 5 章以上没有冲突/悬念的段落
3. **钩子不断**：每章结尾必须有让读者想看下一章的理由
4. **张力整体上升**：全书张力曲线必须整体向上，不能平走

### 商业原则

1. **签约卷最密**：前 30 章节奏最快、梗最密、钩子最强
2. **付费点设计**：每个 VIP 章节开头必须有「不看就错过」的信息
3. **追读友好**：每章独立可读（有开头有结尾），但连起来更好
4. **留白空间**：为读者讨论/猜测留出空间（不要把所有答案都给出）

## 使用示例

### 从 200 章扩展到 250 章

```
目标：+50 章
策略：
  1. 暗网世界层 (ch41-50): 10 → 15 章 (+5)
  2. 跨平台战争 (ch55-65): 10 → 15 章 (+5)
  3. 新增「信力觉醒运动」插槽 (卷三中): +15 章
  4. 新增「古代真道遗产」插槽 (卷三后): +15 章
  5. 苏暮寒动摇弧线 (ch150-165): 15 → 25 章 (+10)
  总计: +50 章 ✓
```

### 根据读者反馈扩展

```
反馈：「钱多多的转变太突然，想看更多他的心路历程」
操作：
  1. 在 ch65-72（钱多多崩塌弧）扩展 +5 章
  2. 新增「钱多多底层生活」插槽 (ch73-78): +5 章
  3. 验证：角色成长弧线是否更自然
  4. 验证：节奏是否仍然紧凑
```
