# anti-ai-generation-constraints

## 定位

AI 检测工具（GPTZero、Originality.ai、知网 AIGC）主要检测 5 个维度。本 skill 在生成 prompt 中注入约束，从源头对抗这 5 个维度。

## AI 检测的 5 个核心维度 + 对抗策略

### 维度 1：困惑度 (Perplexity)

**检测原理**：AI 总选最可能的下一个词，导致文本困惑度低（太「顺」了）。
**人类特征**：会用意外的词、生僻的比喻、不常见的搭配。

**对抗约束（注入 prompt）**：
```
【词汇约束】
- 每 500 字必须有 1 个「意外用词」：用低频同义词替代高频词
  例：「走」→「蹭」「挪」「溜」；「看」→「瞟」「觑」「扫」
- 比喻必须用非常规意象，禁止：如同XX一般、宛如XX、像XX一样（这三个句式本身就是 AI 标记）
- 每章至少 3 处「只有这个角色会用的词」（角色专属词汇表）
```

### 维度 2：突发性 (Burstiness)

**检测原理**：AI 生成的句子长度和复杂度非常均匀。人类写作有极大波动。
**人类特征**：长短句剧烈交替，有极短的爆发句（1-4 字），也有极长的复杂句。

**对抗约束（注入 prompt）**：
```
【句式约束】
- 句长必须有 ≥3x 波动：最短句 ≤5 字，最长句 ≥40 字
- 每 300 字必须有 1 个极短句（1-5 字），用于情绪爆发或节奏切换
  例：「完了。」「他笑了。」「不可能。」「滚。」
- 禁止连续 3 句句长相近（差异 <5 字）
- 段落长度必须有 ≥2x 波动：有 1-2 句的短段，也有 8-10 句的长段
```

### 维度 3：句式重复度

**检测原理**：AI 倾向重复使用相同句式结构（主谓宾、因果、转折）。
**人类特征**：句式多变——倒装、省略、口语化、碎片句。

**对抗约束（注入 prompt）**：
```
【结构约束】
- 禁止连续 3 句使用相同句式开头
- 每 500 字必须有 1 个倒装句或省略句
- 对话中必须有断句/省略/语气词：「那个……」「行吧。」「嗯？」
- 内心独白必须有碎片化思维：不完整句、跳跃、自问自答
- 禁止「他想到了什么，于是做了什么」这种因果模板连续出现
```

### 维度 4：连接词/虚词密度

**检测原理**：AI 过度使用连接词（然而/不过/但是/同时/此外）和虚词（渐渐/缓缓/微微）。
**人类特征**：少用连接词，靠语境和段落切换表达转折。

**对抗约束（注入 prompt）**：
```
【禁用词表】
绝对禁用（出现即判定 AI）：
  渐渐、缓缓、微微、淡淡、轻轻、默默、悄悄
  似乎、仿佛、宛如、犹如、好像、如同
  毫无疑问、无可置疑、事实上、不言而喻
  值得一提的是、需要注意的是、不得不说

限制使用（每章 ≤2 次）：
  然而、不过、但是、可是、只是
  同时、此外、另外、与此同时
  其实、实际上

替代策略：
  - 转折不用连接词，用短句切换：「他笑了。笑完就动了手。」
  - 递进不用「而且」，用动作承接：「刀落下。血溅出。人倒了。」
  - 因果不用「因为所以」，用时间顺序暗示
```

### 维度 5：情感表达方式

**检测原理**：AI 直接告知情感（「他感到愤怒」），人类通过动作/细节展示。
**人类特征**：show don't tell，用身体反应和环境细节传达情绪。

**对抗约束（注入 prompt）**：
```
【展示约束】
- 禁止直接写情绪词：愤怒、悲伤、开心、害怕、紧张、兴奋、失望
- 必须通过以下方式展示情绪：
  · 身体反应：拳头攥紧、牙关咬合、瞳孔收缩、手指发抖
  · 环境感知变化：「空气变冷了」「声音远了」「光线刺眼」
  · 行为异常：说话变快/变慢、动作变大/变小、注意力转移
  · 内心碎片：不完整的念头、重复的词、突然的跳跃
- 唯一例外：角色自己说出情绪词（对话中可以说「我很生气」）
```

## 完整 prompt 注入模板

将以下内容追加到每章生成 prompt 的末尾：

```
§ 反AI检测约束（必须遵守，违反任何一条即判定为不合格）

1. 句长波动：最短句≤5字，最长句≥40字，禁止连续3句句长相近
2. 每300字1个极短句（1-5字）用于节奏切换
3. 每500字1个意外用词（低频同义词替代高频词）
4. 禁止连续3句相同句式开头
5. 每500字1个倒装句或省略句
6. 对话必须有断句/省略/语气词，禁止每句都完整
7. 内心独白必须有碎片化思维（不完整句、跳跃）
8. 绝对禁用词：渐渐/缓缓/微微/淡淡/轻轻/默默/悄悄/似乎/仿佛/宛如/犹如/毫无疑问/不言而喻/值得一提
9. 限制词（每章≤2次）：然而/不过/但是/可是/同时/此外/其实
10. 禁止直接写情绪词，必须通过身体反应/环境/行为展示
11. 段落长度必须有波动：有1-2句短段，有8-10句长段
12. 每章至少3处角色专属用词（只有这个角色会说的话）
```

## 使用方式

### 方式 1：注入 worldview-note（当前可用）

在 `writer-imitate-range --worldview-note` 末尾追加上述约束。

### 方式 2：注入 imitation prompt 模板（需改代码）

在 `novel_analyzer/llm/prompts.py` 的 `build_chapter_imitation_prompt()` 中追加 §反AI检测 段落。

### 方式 3：作为 skill 在 harness pipeline 中调用

在 `imitation_harness_service.py` 的 skill pipeline 中加入本 skill 作为 pre-generation 约束注入。

## 验证方法

生成后用以下指标验证：

| 指标 | 阈值 | 检测方法 |
|------|------|---------|
| 句长标准差 | ≥12 字 | `statistics.stdev(sentence_lengths)` |
| 极短句比例 | ≥5% | `count(len≤5) / total_sentences` |
| 禁用词出现次数 | 0 | 正则匹配 |
| 限制词出现次数 | ≤2 | 正则匹配 |
| 直接情绪词 | 0 | 正则匹配 |
| 连续相同句长 | ≤2 | 滑动窗口检测 |
| 段落长度标准差 | ≥3 句 | `stdev(paragraph_sentence_counts)` |
